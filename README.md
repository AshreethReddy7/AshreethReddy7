## Featured Projects

### [Facial Attendance System](https://github.com/AshreethReddy7/Facial-Attendance-system)
Real-time facial recognition attendance system. Face embeddings via MTCNN + InceptionResnetV1, similarity search with FAISS, CSV-backed attendance logging, and a RAG-based assistant for querying attendance records through a Gradio interface.

`Python` `PyTorch` `OpenCV` `FAISS` `MTCNN` `RAG` `Gradio`

### [Secure E-Health Records (Blockchain)](https://github.com/AshreethReddy7/Secure-Ehealth-Records-Blockchain)
Decentralized healthcare record storage combining a Solidity smart contract, IPFS for encrypted file storage, and an attribute-based access control scheme built on AES-256-GCM and RSA-OAEP.

`Solidity` `Ethereum` `web3.py` `IPFS` `Python` `Cryptography`

### [Weather Forecast App](https://github.com/AshreethReddy7/weather-forecast-app)
Responsive weather forecast web app built with vanilla JavaScript, consuming a live weather API.

`JavaScript` `HTML` `CSS`
